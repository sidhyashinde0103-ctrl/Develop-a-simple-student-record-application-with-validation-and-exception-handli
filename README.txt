STUDENT RECORD MANAGER — PPS MINI PROJECT

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server".
   If Live Server is not installed, install the "Live Server" extension by Ritwick Dey.
   You can also double-click index.html to open it in a browser.

FEATURES
- Add, edit and delete student records
- Search by name, roll number, course or email
- Filter by course
- Input validation (required fields, name, email, unique roll number, marks 0–100)
- Exception handling with try/catch
- Dashboard statistics
- Export records to CSV
- Browser localStorage saves records on this device/browser

IMPORTANT
This is a front-end mini-project demonstration. Records are saved in the current browser only.
Clearing browser site data may remove saved records. It does not use a server or shared database.

PPS CONCEPTS TO EXPLAIN
- Validation: checking user input before saving.
- Exception handling: try/catch handles unexpected errors without crashing the application.
- Arrays and objects: student records are stored as JavaScript objects in an array.
- Functions: separate functions handle validation, saving, rendering, editing and deleting.
